Added regression coverage
-------------------------
- Full OHLCV dataset fingerprint changes when any candle value changes.
- run_id reproducibility across full-window and OOS scope for identical data/config.
- Cross-module OOS cohort count and global entry/exit index consistency.
- OOS entry attribution uses direction-adjusted signal score and realized net account returns.
- Moving-block bootstrap interval generation and insufficient-sample handling.
- Full-window first executable fill aligns with the first OOS fill candle.
- Forecast fails closed on impossible OHLC data.
- OOS deployment eligibility blocks negative/expired/mismatched/gapped evidence.
- Evidence store is keyed by exact source/symbol/timeframe/config fingerprint.
- Live gate allows a trade only after matching positive OOS evidence and existing EV/R:R/edge checks pass.
- Epoch candle timestamps are used in Exit Path and Trade Failure reports.

Market-data validation
----------------------
Not performed in this environment. No live or user-provided OHLCV dataset was run for this release validation. Profitability, positive expectancy, deployability or any return claim is therefore not asserted.

Safety behavior
---------------
Deployment gate defaults to require fresh matching OOS evidence. Missing, expired, negative, low-sample, non-gap-free, non-frozen or cohort-mismatched evidence results in NO TRADE. The existing cost-aware EV, risk/reward, edge-strength and restricted-hours checks remain active.

Reproducibility
---------------
A local strategy_validation_evidence.json is generated at runtime after Walk-Forward. It is user/machine-specific state and is intentionally excluded from the release archive. config.json and agent_journal.db are also not bundled.
