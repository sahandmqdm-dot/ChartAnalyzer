ChartAnalyzer V6.8.0 Upgrade

1) برنامه را متوقف کنید.
2) از پوشه فعلی پروژه یک نسخه پشتیبان بگیرید.
3) محتوای ZIP را در پوشه پروژه استخراج کنید و فایل‌های موجود را جایگزین کنید.
4) config.json و agent_journal.db شخصی خود را حفظ کنید؛ آن‌ها را با نسخه دیگری جایگزین نکنید.
5) وابستگی‌ها را در صورت نیاز نصب کنید:
   python -m pip install -r requirements.txt
6) آزمون‌ها:
   python -m pytest -v
7) اجرا:
   python app.py
8) برای تولید گزارش جدید، Walk-Forward را اجرا کنید. بخش Trade Failure Intelligence در خروجی Walk-Forward ظاهر می‌شود.

V6.8.0 منطق سیگنال یا پارامترهای استراتژی را تغییر نمی‌دهد. گزارش خروج‌های زودهنگام counterfactual است و نتیجه معاملاتی قابل اجرا محسوب نمی‌شود.
